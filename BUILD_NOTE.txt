Updated: 2026-10-23 (UTC+8)

The supported build recipe in this repository is:
  .github/workflows/build.yml

GitHub Actions runs on push to main or manual workflow_dispatch. It builds
the Windows resource and C++17 Win32 executable with MinGW-w64, collects
runtime DLLs from the actual g++.exe directory, and uploads:
  AutoUnwrap-Windows-x64 / AutoUnwrap-Windows-x64.zip

Extract the entire package before running AutoUnwrap.exe. Keep the supplied
libwinpthread-1.dll, libgcc_s_seh-1.dll and libstdc++-6.dll beside the EXE.
The build uses -static-libgcc and -static-libstdc++, not full static linking.
Bandizip bz.exe or 7-Zip 7z.exe/7zz.exe is installed separately.

The older build_mingw.sh mentioned in historical notes is not present in
this repository. Do not assume those old Linux instructions are complete.
Generated EXE/DLL files and personal AppData settings are not source files.
