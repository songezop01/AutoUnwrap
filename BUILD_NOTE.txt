Auto Unwrap v3.0.3

This package contains the v3.0.3 source fix for Windows automatic deletion.
The existing v3.0.2 executable was intentionally not included because this
Linux environment does not have a MinGW-w64 cross-compiler, so shipping the
old EXE as v3.0.3 would be misleading.

Build on a machine with MinGW-w64:
  ./build_mingw.sh

The resulting file will be:
  dist/AutoUnwrap.exe
